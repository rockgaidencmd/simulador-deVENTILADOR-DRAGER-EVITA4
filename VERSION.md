# Versión publicada

**v5**

La pantalla de inicio del simulador muestra este número abajo del todo, bajo el
aviso legal. Si en tu dispositivo ves un número distinto —o no ves ninguno— lo
que estás usando es una versión anterior guardada en la caché o publicada por
GitHub Pages, no la última.

## Historial

| Versión | Cambios |
|---|---|
| v5 | Códigos compartidos con la app maestra MS360 (colección `codigos_maestra`) |
| v4 | Puerta de activación estricta, marca de versión visible, corrección de recarga al instalar |
| v3 | Valores medidos y monitor en una sola pestaña plegable; caché versionada |
| v2 | Curvas y valores plegables para liberar la zona de controles |
| v1 | Primera versión del simulador |

## Comprobar qué versión está publicada

En el repositorio: **Actions → pages build and deployment**. La compilación más
reciente debe corresponder al último commit de `main`. Si no coincide, hay que
forzar una publicación nueva desde **Settings → Pages**.
